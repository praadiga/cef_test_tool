    Player reminder: configure console-log and console-log-limit in the player separately. This page only emits browser console output.

    Token-bucket tests should expect an initial burst around 10 messages per CEF severity level, then about 1/s per level when player rate limiting is enabled. This is not a hard “10 logs per 10 seconds” cap.

    FATAL is emitted with console.error, so many CEF builds classify it as ERROR.

    Preset guide: baseline_burst uses player console-log=4, limit 0; rate_limit_burst, rate_limit_sustained, refill_after_idle, and error_under_info_flood use player console-log=4, limit 1; per_level_mixed uses player console-log=5, limit 1; severity_error_only uses player console-log=2, limit 0.
